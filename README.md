# Shrey Jain — 3D Interactive Portfolio

Production-ready 3D interactive personal portfolio website for **Shrey Jain**, second-year B.Tech CSE (AI & ML) student at SRMIST.

## 🚀 Stack
- **Framework**: React 18 + Vite + TypeScript
- **3D / Canvas**: WebGL Canvas 3D particle constellation & wireframe mesh
- **Styling**: Tailwind CSS v4 + PostCSS
- **Icons**: Lucide React + Custom Inline Social SVGs
- **Deployment**: Vercel

## 📦 Local Development

```bash
# Install dependencies
npm install --legacy-peer-deps

# Start dev server
npm run dev

# Build for production
npm run build
```

## 🌐 Deployment on Vercel

1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/SHREYJAIN134/shrey-jain-portfolio.git
   git push -u origin main
   ```
2. Import `shrey-jain-portfolio` on [Vercel](https://vercel.com/new).
3. Click **Deploy**.
